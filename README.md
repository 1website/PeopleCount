# ប្រព័ន្ធគ្រប់គ្រងស្ថិតិប្រជាជន និងគ្រួសារកម្ពុជា
## (Cambodia Demographic, Family Census & Education Tracking System)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងសម្រាប់គ្រប់គ្រងទិន្នន័យប្រជាជន គ្រួសារ អប់រំ និងការបោះបង់ការសិក្សា តាមរចនាសម្ព័ន្ធរដ្ឋបាលភូមិសាស្ត្រកម្ពុជា ព្រមទាំងគាំទ្រ **Offline Mode (PWA)** សម្រាប់អ្នកស្រង់ស្ថិតិចុះមូលដ្ឋាន។

---

### 🌟 មុខងារសំខាន់ៗទាំង ៥ នៃប្រព័ន្ធ (Core Modules)

#### ១. មុខងារគ្រប់គ្រងរដ្ឋបាលភូមិសាស្ត្រ (Geographic Hierarchy)
- កំណត់ និងជ្រើសរើសទីតាំងតាម ៤ លំដាប់ថ្នាក់៖ **ខេត្ត/រាជធានី -> ស្រុក/ខណ្ឌ -> ឃុំ/សង្កាត់ -> ភូមិ**
- ភ្ជាប់ជាមួយ**លេខកូដរដ្ឋបាលសម្គាល់ស្វ័យប្រវត្តិតាមស្តង់ដារជាតិ** (ខេត្ត ២ ខ្ទង់, ស្រុក ៤ ខ្ទង់, ឃុំ ៦ ខ្ទង់, ភូមិ ៨ ខ្ទង់)
- បែងចែកសិទ្ធិ និងចាត់តាំងអ្នកស្រង់ស្ថិតិតាមតំបន់នីមួយៗ (Assigned Jurisdiction)។

#### ២. មុខងារគ្រប់គ្រងព័ត៌មានគ្រួសារ (Family Profile Management)
- បង្កើតលេខកូដសម្គាល់គ្រួសារស្វ័យប្រវត្តិតាមទម្រង់ស្តង់ដារ `FAM-{VillageCode}-{Sequence}` ឧ. `FAM-12010101-0001`
- កំណត់ប្រភេទគ្រួសារ៖ **ក្រ១ (IDPoor 1)**, **ក្រ២ (IDPoor 2)**, និង **ទូទៅ (General)**
- បង្ហាញសមាជិកគ្រួសារទាំងអស់ក្នុងទម្រង់បញ្ជីតារាងតែមួយ (Unified Family Card & Table)។

#### ៣. មុខងារចុះឈ្មោះ និងកែប្រែព័ត៌មានសមាជិកគ្រួសារ (Individual Data Entry)
- **ព័ត៌មានផ្ទាល់ខ្លួន**៖ គោត្តនាម-នាម, ភេទ, សញ្ជាតិ, ថ្ងៃខែឆ្នាំកំណើត (DOB)
- **គណនាអាយុ Real-time ស្វ័យប្រវត្តិ**៖ គ្រាន់តែរើស ឬវាយថ្ងៃខែឆ្នាំកំណើត ប្រព័ន្ធគណនាអាយុភ្លាមៗ
- **ទំនាក់ទំនងក្នុងគ្រួសារ**៖ មេគ្រួសារ, ប្រពន្ធ/ប្តី, កូន, ឪពុក/ម្តាយ, សាច់ញាតិ, ផ្សេងៗ
- **ទិន្នន័យអប់រំ និងឯកសាររដ្ឋបាល**៖
  - កម្រិតវប្បធម៌ / ចូលរៀន (មិនបានរៀន, ចូលរៀនបឋម, ចូលរៀនមធ្យម, ឧត្តមសិក្សា)
  - ករណីបោះបង់ការសិក្សា (បញ្ជាក់កម្រិតថ្នាក់ដែលបោះបង់ e.g. ថ្នាក់ទី ៧) ឬបង្អង់ការសិក្សា
  - ស្ថានភាពសំបុត្រកំណើត (មាន / គ្មាន)
  - ចំណាំផ្សេងៗ (ពិការភាព, មុខរបរ, ទីកន្លែងស្នាក់នៅបច្ចុប្បន្ន)។

#### ៤. មុខងារទាញរបាយការណ៍ និងស្ថិតិស្វ័យប្រវត្តិ (Reporting & Dashboard)
- **គណនាសរុបស្វ័យប្រវត្តិ (KPI Metrics)**៖
  - ចំនួនប្រជាជនសរុប (បំបែក ស្រី/ប្រុស និងភាគរយ)
  - អត្រាអ្នកមាន/គ្មានសំបុត្រកំណើត
  - ចំនួនកុមារដល់អាយុចូលរៀន (៣-៥ ឆ្នាំ, ៦-១១ ឆ្នាំ, ១២-១៤ ឆ្នាំ, ១៥-១៧ ឆ្នាំ)
  - អត្រាបោះបង់ការសិក្សា (Dropout Rate %) និងតារាងបំបែកតាមកម្រិតថ្នាក់
- **នាំចេញទិន្នន័យ (Export)**៖
  - **Excel (.xlsx)**៖ មានក្បាលលិខិតជាតិ បន្ទាត់ព្រំដែនតារាងត្រឹមត្រូវ និងទិន្នន័យលម្អិត
  - **ទម្រង់ក្រដាសរដ្ឋបាល A4 Landscape (Print/PDF)**៖ មានក្បាលលិខិតផ្លូវការ *"ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ"*, ចំណងជើង *សៀវភៅស្ថិតិប្រជាជនភូមិ*, និងកន្លែងចុះហត្ថលេខា/ត្រារបស់ *អ្នកស្រង់ស្ថិតិ*, *មេភូមិ*, និង *មេឃុំ*។

#### ៥. មុខងារបច្ចេកវិទ្យាបន្ថែម (Technical Features)
- **Offline Mode (ប្រើពេលគ្មានអ៊ីនធឺណិត)**៖ បច្ចេកវិទ្យា PWA + Service Worker + IndexedDB អនុញ្ញាតឱ្យអ្នកស្រង់ស្ថិតិចុះបញ្ចូលទិន្នន័យតាមទូរស័ព្ទ/ថេប្លេតនៅទីតាំងផ្ទាល់ រួចប្រព័ន្ធនឹង Sync ស្វ័យប្រវត្តិចូល Server ពេលមានអ៊ីនធឺណិតវិញ (មានប៊ូតុង Manual Sync ផងដែរ)
- **Role-Based Access Control (RBAC)**៖
  - **Admin ថ្នាក់លើ (Super Admin)**: គណនី `admin` / `admin123`
  - **អ្នកត្រួតពិនិត្យ (Reviewer / មេឃុំ / មេភូមិ)**: គណនី `reviewer` / `reviewer123`
  - **អ្នកស្រង់ទិន្នន័យ (Data Collector / Enumerator)**: គណនី `collector` / `collector123`

#### ៦. មុខងារគ្រប់គ្រងអ្នកប្រើប្រាស់ (Admin & User Management)
- **បញ្ជីគណនីអ្នកប្រើប្រាស់**៖ មើលបញ្ជីគណនីទាំងអស់ ឈ្មោះពេញ ឈ្មោះគណនី តួនាទី ដែនសមត្ថកិច្ច (ខេត្ត/ស្រុក/ឃុំ/ភូមិ) និងស្ថានភាពដំណើរការ
- **បង្កើតគណនីថ្មី (Add User)**៖ កំណត់ Username, Password, Role (Admin, Reviewer, Collector) និងចាត់តាំងកូដរដ្ឋបាលភូមិសាស្ត្រ
- **កែប្រែព័ត៌មាន (Edit User)**៖ កែប្រែឈ្មោះ តួនាទី ដែនសមត្ថកិច្ច និងផ្លាស់ប្តូរពាក្យសម្ងាត់ថ្មី (Password Reset)
- **ផ្អាក ឬបើកដំណើរការ (Toggle Active/Suspend)**៖ ផ្អាកគណនីបណ្តោះអាសន្ន ឬបើកឱ្យដំណើរការឡើងវិញភ្លាមៗ
- **លុបគណនី (Delete User)**៖ លុបគណនីដែលលែងប្រើប្រាស់ចេញពីប្រព័ន្ធ ជាមួយសុវត្ថិភាពទប់ស្កាត់ការលុបគណនីផ្ទាល់ខ្លួន។

### 🚀 របៀបដំណើរការប្រព័ន្ធ (How to Run)

1. **បើក Terminal រួចចូលទៅកាន់ Folder គម្រោង**៖
   ```powershell
   cd d:\PeopleCount
   ```

2. **ដំណើរការ Web Server**៖
   ```powershell
   py run.py
   ```

3. **បើក Browser (Chrome, Edge, Firefox)**៖
   - ផ្ទាំងកម្មវិធីចម្បង៖ **http://localhost:8000**
   - ផ្ទាំងបោះពុម្ពទម្រង់រដ្ឋបាល៖ **http://localhost:8000/print**
   - API Swagger Documentation៖ **http://localhost:8000/docs**
   - ទាញយក Excel ផ្ទាល់៖ **http://localhost:8000/api/reports/export/excel**

4. **ដំណើរការតេស្តស្វ័យប្រវត្តិ (Automated Tests)**៖
   ```powershell
   py test_system.py
   ```
